# Mixer Studio 0.4 — คัดเพลงซ้ำจาก Song.dbf

## เตรียมต้นทาง

ใช้ Windows 10/11 แบบ 64 บิต แตก ZIP แล้วเปิด MixerStudio.exe

ช่อง Extreme, EMK และ NCN เริ่มว่างทุกครั้งที่เปิดโปรแกรม เมื่อผู้ใช้เลือก Extreme โปรแกรมเติม EMK/NCN ตามพาธมาตรฐานให้อัตโนมัติ หากไม่พบจะแจ้งสถานะ และยังเปลี่ยน EMK/NCN แยกเองได้ตามที่เก็บจริง โปรแกรมไม่อ่านค่าตั้งโฟลเดอร์เดิมตอนเปิด ยกเว้นเมื่อผู้ใช้เลือกเปิดไฟล์งานที่บันทึกไว้โดยตรง:

- EMK: `<Extreme>/Songs/MIDI/EMK`
- NCN: `<Extreme>/Songs/MIDI/NCN` ภายในมี `Song`, `Lyrics`, `Cursor`

จากนั้นเปิด Song.dbf จากคลังปัจจุบัน ปกติอยู่ใน `<Extreme>/Data/`

## คัดเพลงซ้ำ

มีสองเกณฑ์ตรงกับไฟล์อ้างอิง:

- **ชื่อเพลง + เนื้อเพลง** ใช้คู่ค่า `TITLE` และ `LYR_TITLE`
- **นักร้อง + เนื้อเพลง** ใช้คู่ค่า `ARTIST` และ `LYR_TITLE`

ใช้ข้อมูล DBF ที่อ่านด้วย Windows-874 รักษาค่าของฟิลด์ตามเดิม ไม่มีการตัดคำ ลบเครื่องหมาย รวมตัวพิมพ์ หรือเทียบเสียง

ตัวเลือก **เลือก EMK ก่อน** ทำให้เพลง EMK ถูกเก็บก่อนเมื่อข้อมูลซ้ำกัน เอาเครื่องหมายออกเพื่อให้ NCN มาก่อน หากซ้ำในชนิดเดียวกันจะใช้ลำดับข้อมูลตามการเรียง SUB_TYPE ของต้นฉบับ

มุมมองตารางแยกเพลงที่เก็บไว้ เพลงซ้ำที่คัดออก และเปรียบเทียบทุกกลุ่ม ช่องค้นหากรองเฉพาะสิ่งที่แสดง ไม่เปลี่ยนรายการส่งออก ตัวอย่างเช่น คัดเหลือ 100 เพลงแต่ค้นหาเห็น 3 เพลง การส่งออกยังใช้เพลงที่คัดเหลือทั้ง 100 เพลง

ตารางแสดงฟิลด์จาก DBF ครบและเลื่อนแนวนอนได้ ตารางเป็นแบบอ่านอย่างเดียว ใช้หน้ากลุ่มเพื่อเลือกเพลงที่จะเก็บ โปรแกรมไม่บันทึกแก้ไข Song.dbf

## ดูกลุ่มและเลือกเพลงที่เก็บ

หลังคัดซ้ำ กด **ดู/เลือกเพลงในกลุ่ม** เลือกกลุ่มทางซ้ายและดูเหตุผลที่จัดว่าซ้ำ รวมทั้งรายการ EMK/NCN และเนื้อเพลงจาก DBF เลือกแถวแล้วกด **เก็บเพลงนี้** ทำได้หลายกลุ่ม จากนั้นกด **ใช้ตัวเลือก** เพื่อยืนยัน หรือยกเลิกเพื่อคงผลเดิม

ตัวเลือกที่เลือกเองมีลำดับเหนือ EMK/NCN อัตโนมัติ และแยกตามเกณฑ์คัด การเปิด DBF ใหม่หรือคืนรายการทั้งหมดล้างตัวเลือกเดิม

## สรุปก่อนทำงาน

ก่อนสำเนา ย้าย หรือพักเพลงซ้ำ จะมีหน้าสรุปจำนวนต้นฉบับ เพลงที่เก็บ เพลงซ้ำ ชุดที่พร้อม ชุดที่จะข้าม จำนวนไฟล์ ขนาดไฟล์รวม และพื้นที่ปลายทางว่าง พร้อมตัวอย่างรหัสและเหตุผลที่ข้าม ยกเลิกที่หน้าสรุปได้ก่อนมีการเปลี่ยนไฟล์ หากตรวจพบพื้นที่ไม่พอจะไม่เริ่มการสำเนา

## ส่งออก

ตั้งตัวอักษรเริ่มต้น `0–9` หรือ `A–Z` และจำนวนเพลงต่อโฟลเดอร์ `1–99,999` ค่าเริ่มต้น 20,000

หรือเลือก **ไม่จำกัด** เพื่อให้โปรแกรมไม่แบ่งโฟลเดอร์ตามจำนวน และเก็บทั้งหมดในตัวอักษรเริ่มต้นที่เลือก ช่องจำนวนเพลงจะถูกปิดการแก้ไขขณะเลือกโหมดนี้ เลขรันต่อโดยไม่ตัดเหลือห้าหลัก เช่น `A99999` → `A100000` → `A100001` แต่ละประเภทมีโฟลเดอร์ของตนเองตามเดิม ไม่มีเพดานจากตัวเลือกจำนวนต่อโฟลเดอร์ แต่ยังขึ้นกับพื้นที่จัดเก็บและทรัพยากรเครื่อง รหัสที่ยาวกว่าหกตัวต้องทดสอบกับ Extreme Karaoke รุ่นที่ใช้งาน

แต่ละประเภทเริ่มเลขของตัวเอง เช่น `0/000001.emk` และ `Song/0/000001.mid` เมื่อครบจำนวนจะไปตัวอักษรถัดไป เช่น `9` ไป `A` ไฟล์ NCN จะมีชื่อฐานตรงกันทั้ง MIDI, Lyrics และ Cursor

- **สำเนาเพลงที่เก็บ → Export** คงไฟล์เดิมไว้และสำเนาเป็นรหัสใหม่
- **ย้ายเพลงที่เก็บ → Export** นำไฟล์ที่เก็บออกจากต้นทางและเปลี่ยนรหัสในปลายทาง มีคำถามยืนยันสองครั้งตามลำดับงานต้นฉบับ

ปลายทางตามไฟล์อ้างอิง:

```
<Extreme>/Songs/MIDI/EMK NCN Mixer Export/
  EMK/Export/<ตัวอักษร>/<รหัสใหม่>.emk
  NCN/Export/Song/<ตัวอักษร>/<รหัสใหม่>.mid
  NCN/Export/Lyrics/<ตัวอักษร>/<รหัสใหม่>.Lyr
  NCN/Export/Cursor/<ตัวอักษร>/<รหัสใหม่>.Cur
```

ไฟล์อ้างอิงชุดนี้คัดชุดที่ไม่ซ้ำออกไปด้วยการสำเนาหรือย้าย เมื่อย้ายแล้ว เพลงที่คัดออกว่าซ้ำยังคงอยู่ต้นทาง โปรแกรมนี้ทำตามลำดับดังกล่าว ไม่ได้เพิ่มปุ่มลบเพลงซ้ำถาวรขึ้นมาเอง

หลังย้ายให้จัดทำฐานข้อมูลใน Extreme ใหม่ แล้วเปิด Song.dbf ใหม่ก่อนทำงานต่อ

## ไฟล์ขาดและการยกเลิก

ปุ่ม **ตรวจไฟล์ก่อนส่งออก** แสดงจำนวนชุดไฟล์พร้อมและไฟล์ขาด หาก NCN ขาด Lyrics หรือ Cursor จะข้ามทั้งชุดและบันทึกรายงาน ไม่ย้าย MIDI เพียงส่วนเดียว การแก้กรณีไฟล์ขาดนี้เป็นความต่างจากการจัดการข้อผิดพลาดของต้นฉบับ ดู REFERENCE-BEHAVIOR.md

กดหยุดได้ โปรแกรมทำชุดไฟล์เพลงปัจจุบันให้เสร็จก่อนหยุด เพื่อให้ชุด NCN ไม่แยกกลางทางจากการกดยกเลิก

รายงาน JSONL อยู่ในโฟลเดอร์ Export หลัก ระบุแหล่งเดิม ปลายทางจริง รหัสเก่า/ใหม่ รายการข้ามและข้อผิดพลาด ไม่เขียนทับไฟล์ปลายทางที่มีอยู่ หากชื่อหลักซ้ำจะเติมวันเวลานำหน้าตามรูปแบบอ้างอิง

## พักเพลงซ้ำและกู้คืน

กด **พักเพลงซ้ำ…** หลังคัดและตรวจเลือกผู้เก็บแล้ว โปรแกรมแสดงสรุปก่อนย้ายเฉพาะรายการซ้ำที่คัดออกไปที่ `<Export>/พักเพลงซ้ำ/<วันเวลา_รหัส>/` โดยรักษาชื่อและโครงสร้างต้นทางไว้ ไม่เปลี่ยนรหัสเพลงในที่พัก

ถ้าแถวซ้ำอ้างไฟล์เดียวกับเพลงที่เก็บ โปรแกรมข้ามทั้งชุดนั้น เพราะการคัดซ้ำใน DBF ไม่ได้หมายความว่ามีไฟล์จริงสองชุดเสมอไป NCN ที่ขาดไฟล์ประกอบจะถูกข้ามด้วย

เก็บ `mixer-hold.json`, `mixer-hold.journal.jsonl` และไฟล์ที่พักไว้ด้วยกัน กด **กู้คืนเพลง…** เลือก `mixer-hold.json` โดยเลือกโฟลเดอร์ EMK/NCN ให้ตรงกับต้นทางเดิมก่อน โปรแกรมตรวจ checksum และคืนพาธเดิม ถ้าต้นทางมีไฟล์อยู่แล้วหรือไฟล์พักถูกแก้ไข จะไม่เขียนทับและแจ้งรายการที่คืนไม่ได้ แก้ข้อขัดข้องแล้วเปิดรายการเดิมทำต่อได้

การกดยกเลิกพักจะหยุดระหว่างชุดเพลง เมื่อเกิดข้อผิดพลาดระหว่างย้ายชุด NCN โปรแกรมพยายามคืนไฟล์ที่ย้ายในชุดนั้นแล้ว หากมีสิ่งขัดขวางจะเก็บรายการไว้เพื่อกู้คืนผ่านประวัติ

หลังย้าย พัก หรือกู้คืน ให้จัดทำฐานข้อมูล Extreme ใหม่และเปิด Song.dbf ใหม่ก่อนจัดไฟล์ครั้งต่อไป

## บันทึกงานไว้ทำต่อ

กด **บันทึกงาน…** ได้ไฟล์ `.mixwork` เก็บข้อมูล DBF ที่อ่านแล้ว เกณฑ์คัด ลำดับ EMK/NCN เพลงที่เลือกเก็บเอง พาธโฟลเดอร์ และการตั้งค่าส่งออก กด **เปิดงาน…** เพื่อคืนสถานะเหล่านี้โดยไม่ต้องคัดเลือกใหม่ ไฟล์งานไม่รวมไฟล์เพลงจริงและไม่ใช่สำเนาสำรองเพลง

ถ้าตรวจพบ DBF ต้นทางเปลี่ยนไปจากตอนบันทึก หรือไฟล์งานบันทึกหลังมีการย้ายเพลง โปรแกรมให้เปิดฐานข้อมูลใหม่ก่อนจัดไฟล์ เพื่อไม่ใช้สถานะเก่าจัดการคลังที่เปลี่ยนแล้ว

## ขอบเขตที่ยืนยันแล้ว

ได้ตรวจตรรกะใน EXE อ้างอิง ทดสอบตัวอ่าน DBF ใหม่เทียบกับตัวอ่าน DBF จริงจากไฟล์นั้นด้วยข้อมูลจำลอง และเทียบเกณฑ์คัดทั้งสองโหมดกับนิพจน์ต้นฉบับ ชุดทดสอบ Windows ทดสอบปุ่มคัดซ้ำ เปลี่ยนลำดับ EMK/NCN มุมมอง ค้นหา สำเนา และย้ายด้วยไฟล์จำลอง

ยังไม่ได้เทียบผลแบบครบทุกกรณีด้วยคลังเพลงจริง จึงยังไม่อ้างว่าเหมือน 100% ในทุกกรณี
