# Mixer Studio 0.1 — โปรแกรม Windows รุ่นเริ่มต้น

โปรแกรมใหม่สำหรับตรวจไฟล์และคัดลอกคลัง EMK / NCN ด้วยหน้าจอภาษาไทย ใช้งานในเครื่อง ไม่ต้องเชื่อมต่ออินเทอร์เน็ต

## เปิดใช้งาน

1. แตก ZIP ทั้งหมดไปยังโฟลเดอร์ในเครื่อง Windows 10/11 แบบ 64 บิต
2. เปิด MixerStudio.exe ไม่ต้องติดตั้ง .NET เพิ่ม
3. เลือกโฟลเดอร์เพลงแล้วกด “สแกนไฟล์” โปรแกรมจะอ่านโฟลเดอร์ย่อยด้วย
4. ค้นหาจากรหัส ชื่อไฟล์ หรือตำแหน่ง กรองรายการที่ต้องตรวจสอบได้
5. ติ๊กเลือกเพลงที่ต้องการคัดลอก หรือกด “เลือกที่แสดงทั้งหมด”
6. เลือกปลายทางที่แยกจากต้นทาง แล้วกด “คัดลอกเพลงที่เลือก”
7. โปรแกรมสร้างโฟลเดอร์ MixerExport_วันเวลา_รหัส พร้อมรายงาน export-report.json

## ความสามารถ

- พบไฟล์หลัก .emk .mid .midi และค้นหาไฟล์ประกอบ .lyr .cur
- จับคู่ไฟล์ NCN ด้วยชื่อฐานเดียวกัน โดยให้ความสำคัญกับไฟล์ในโฟลเดอร์เดียวกัน
- ถ้าจับคู่ได้มากกว่าหนึ่งไฟล์ หรือรหัส MIDI ซ้ำและไม่มีไฟล์ประกอบในโฟลเดอร์เดียวกัน จะแสดงว่าต้องตรวจสอบ
- ไฟล์ประกอบที่จับคู่ไม่ได้จะแสดงในข้อสังเกตหลังสแกน
- ไม่อนุญาตให้คัดลอกรายการที่แจ้งไฟล์ประกอบขาดหรือซ้ำ
- คัดลอกไฟล์จริงโดยคงเส้นทางสัมพัทธ์จากต้นทาง ไม่ย้าย ไม่ลบ ไม่เปลี่ยนชื่อ และไม่เขียนทับงานส่งออกก่อนหน้า
- หยุดสแกนหรือหยุดคัดลอกได้ รายงานระบุจำนวนไฟล์สำเร็จ ข้าม และผิดพลาด
- เมื่อหยุดระหว่างคัดลอก เก็บไฟล์ที่คัดลอกเสร็จไว้ และลบไฟล์ชั่วคราวของไฟล์ที่ยังไม่เสร็จ

## ขอบเขตของรุ่นนี้

เป็นรุ่นเริ่มต้นที่พัฒนาใหม่ ไม่ใช่โปรแกรมเดิมและยังไม่ใช่ตัวแทนที่รองรับทุกฟังก์ชัน

ยังไม่อ่าน Song DBF, ไม่แปลง EMK ↔ NCN, ไม่ซ่อมข้อมูลภายในเพลง, ไม่เล่น MIDI และไม่กรองจากศิลปินหรือเนื้อเพลง
คำว่า “พร้อมคัดลอก” หมายถึงพบไฟล์ ส่วน “พบไฟล์ประกอบครบ” หมายถึงพบชื่อไฟล์ที่จับคู่ได้ ไม่ได้ยืนยันว่าเนื้อหาภายในไฟล์ถูกต้องหรือเล่นได้
ชื่อที่แสดงเป็นชื่อไฟล์ ไม่ใช่ชื่อเพลงจากฐานข้อมูล

การทำฟังก์ชันให้ตรงกับโปรแกรมต้นแบบขั้นต่อไปต้องใช้ไฟล์ DBF และชุดเพลงตัวอย่างที่อนุญาตให้ใช้ทดสอบ พร้อมผลลัพธ์ที่คาดหวังจากโปรแกรมเดิม

## การตรวจสอบในรอบนี้

คอมไพล์และ publish สำหรับ win-x64 สำเร็จ ทดสอบส่วนประมวลผลด้วยไฟล์จำลอง ทั้งการจับคู่ ขาด/ซ้ำ คัดลอกเทียบไบต์ รายงาน ยกเลิกงาน และป้องกันเลือกปลายทางทับซ้อนต้นทาง

สภาพแวดล้อมพัฒนาเป็น Linux จึงยังไม่ได้เปิดทดสอบหน้าจอ WPF บน Windows หรือทดสอบด้วยคลังเพลงจริง ควรเริ่มทดลองกับสำเนาคลังขนาดเล็ก

## สำหรับนักพัฒนา

ใช้ .NET 8 SDK บน Windows และรัน build.ps1 เพื่อสร้าง EXE พร้อม runtime

- App/ — WPF ภาษาไทย
- Core/ — สแกนและคัดลอกไฟล์
- Checks/ — ชุดตรวจสอบส่วนประมวลผล ไม่ต้องใช้ Windows

รันทดสอบ: dotnet run --project Checks/Mixer.Checks.csproj
