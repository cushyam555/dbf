# Mixer Studio — คัดเพลงซ้ำ EMK / NCN

[![Build Windows EXE](https://github.com/cushyam555/dbf/actions/workflows/windows.yml/badge.svg)](https://github.com/cushyam555/dbf/actions/workflows/windows.yml)

โปรแกรม Windows ภาษาไทยสำหรับคัดเพลงซ้ำจาก **Song.dbf** และสำเนาหรือย้ายเพลงที่คัดเหลือไปยัง Export พร้อมจัดรหัสใหม่ ตามการทำงานหลักที่ตรวจพบในไฟล์ EMK NCN Mixer File Reconstruction ที่ใช้เป็นอ้างอิง

**รุ่น 0.2 เปลี่ยนจากรุ่น 0.1 ที่เป็นเพียงตัวจัดไฟล์ มาใช้การคัดเพลงซ้ำจากฐานข้อมูลจริง**

## ดาวน์โหลด Windows EXE

1. เปิด [Build Windows EXE](https://github.com/cushyam555/dbf/actions/workflows/windows.yml)
2. เลือกงานของรุ่นล่าสุดที่แสดงเครื่องหมายถูกสีเขียว
3. ดาวน์โหลด **MixerStudio-Windows-x64** ในส่วน **Artifacts** (ต้องเข้าสู่ระบบ GitHub)
4. แตก ZIP แล้วเปิด **MixerStudio.exe** บน Windows 10/11 แบบ 64 บิต ไม่ต้องติดตั้ง .NET เพิ่ม

ไฟล์ของแต่ละงานเก็บไว้ 30 วัน เจ้าของ repository กด **Run workflow** เพื่อสร้างใหม่ได้

## ฟีเจอร์รุ่น 0.4

- ดูเพลงซ้ำเป็นกลุ่ม พร้อมเหตุผลตามเกณฑ์และข้อมูลเนื้อเพลงที่ใช้เทียบ
- เลือกเพลงที่จะเก็บเองในแต่ละกลุ่ม โดยตัวเลือกนี้มีลำดับเหนือ EMK/NCN อัตโนมัติ
- ดูสรุปก่อนจัดไฟล์: เก็บ/ซ้ำ/พร้อม/ข้าม จำนวนไฟล์ ขนาดข้อมูล และพื้นที่ว่าง พร้อมยืนยันก่อนเริ่ม
- พักเพลงซ้ำไว้ต่างหากและกู้คืนพาธเดิม พร้อมบันทึกการทำงาน ตรวจ checksum และไม่เขียนทับไฟล์ต้นทางที่มีอยู่แล้ว
- บันทึกไฟล์งาน `.mixwork` และเปิดต่อพร้อมข้อมูล DBF เกณฑ์ ตัวเลือกเพลง และการตั้งค่าส่งออก

ไฟล์งานเก็บข้อมูลรายการและตัวเลือก ไม่ได้สำรองไฟล์เพลง ต้องเก็บโฟลเดอร์พักและรายการกู้คืนไว้ด้วยกัน

## การใช้งานตามไฟล์อ้างอิง

1. ช่องโฟลเดอร์เริ่มว่าง เมื่อเลือก Extreme จะเติม EMK/NCN ตามพาธมาตรฐานให้อัตโนมัติ และเปลี่ยนแยกเองได้
2. เปิด **Song.dbf** ที่สร้างจากคลังปัจจุบันใน Extreme Karaoke
3. เลือก **ชื่อเพลง + เนื้อเพลง** หรือ **นักร้อง + เนื้อเพลง** เพื่อคัดซ้ำ
4. ตัวเลือก **เลือก EMK ก่อน** กำหนดว่าจะเก็บ EMK หรือ NCN เมื่อข้อมูลซ้ำกัน
5. ดูรายการที่เก็บ รายการซ้ำ และตารางเปรียบเทียบกลุ่ม ก่อนดำเนินการ
6. เลือกตัวอักษรเริ่มต้น 0–9 / A–Z และจำนวนเพลงต่อโฟลเดอร์ (ค่าเดิม 20,000 สูงสุด 99,999) หรือเลือก **ไม่จำกัด** เพื่อส่งออกทั้งหมดในโฟลเดอร์ตัวอักษรเดียว
7. **สำเนาเพลงที่เก็บ → Export** หรือ **ย้ายเพลงที่เก็บ → Export**

การย้ายจะนำเพลงที่เก็บออกจากต้นทางและเปลี่ยนรหัสใหม่ ส่วนเพลงซ้ำที่คัดออกยังอยู่ต้นทาง เป็นลำดับการทำงานที่พบในไฟล์อ้างอิงชุดนี้ หลังย้ายต้องจัดทำฐานข้อมูลใน Extreme ใหม่

ปลายทาง: `<Extreme>/Songs/MIDI/EMK NCN Mixer Export/` แยก EMK/NCN และ Song/Lyrics/Cursor ตามต้นฉบับ

**โหมดไม่จำกัด:** ไม่มีเพดานจำนวนเพลงที่กำหนดโดยโปรแกรมต่อโฟลเดอร์ ตัวเลขจะยาวขึ้นเมื่อเกิน 99,999 เช่น `A99999` → `A100000` โหมดนี้ต่างจากรูปแบบรหัสหกตัวเดิม ต้องตรวจการรองรับกับ Extreme Karaoke รุ่นที่ใช้งาน และยังขึ้นกับพื้นที่จัดเก็บ/ทรัพยากรเครื่อง

เกณฑ์เนื้อเพลงใช้ค่า **LYR_TITLE ใน DBF** ตามต้นฉบับ ไม่ใช่การเทียบไบต์หรือเสียงของเพลง รายละเอียดเกณฑ์ การตั้งชื่อ และขอบเขตการเทียบอยู่ใน [REFERENCE-BEHAVIOR.md](REFERENCE-BEHAVIOR.md)

## การตรวจสอบ

- ชุดทดสอบข้อมูลจำลองเทียบเกณฑ์คัดกับนิพจน์ในต้นฉบับ ทั้งสองโหมดและทั้งสองลำดับ EMK/NCN
- ทดสอบตัวอ่าน DBF ภาษาไทย การคัดซ้ำ การจับคู่ไฟล์ การแบ่งรหัส การสำเนา การย้าย และรายงาน
- GitHub Actions ทดสอบปุ่มบนหน้าจอ Windows ด้วยฐานข้อมูลและไฟล์จำลอง รวมถึงสำเนาและย้ายจริงภายในโฟลเดอร์ทดสอบชั่วคราว
- ยังไม่ได้ยืนยันความเหมือนครบทุกกรณีจากคลังเพลงจริง ดูขอบเขตและความต่างในเอกสารพฤติกรรม

## สร้างจากซอร์ส

ใช้ .NET 8 SDK บน Windows แล้วรัน `./build.ps1` จะได้ `dist/MixerStudio.exe`

รันทดสอบส่วนประมวลผล: `dotnet run --project Checks/Mixer.Checks.csproj`

รันทดสอบ UI บน Windows: `dotnet run --project UiChecks/Mixer.UiChecks.csproj`
